# Online Shopping System – DBMS

## Project Description

The Online Shopping System is a database project developed using PostgreSQL.
It manages customers, addresses, categories, sellers, products, carts,
orders, reviews, and wishlists.

## Technologies Used

- PostgreSQL
- SQL
- DB Fiddle
- GitHub

## Database Tables

1. Customer
2. Address
3. Category
4. Seller
5. Product
6. Cart
7. Cart_Item
8. Orders
9. Order_Item
10. Review
11. Wishlist

## SQL Files

- `ddl.sql` – Table creation and constraints
- `dml.sql` – Sample data
- `queries.sql` – SQL queries and operations
